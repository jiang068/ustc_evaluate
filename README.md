# 中科大评教自动填写脚本

这是一个 Tampermonkey 油猴脚本，用于在中科大教学质量管理平台页面上自动填写评教问卷。

## 安装

1. 浏览器安装 Tampermonkey 油猴扩展。
2. 打开 Tampermonkey 管理面板，点击新建脚本。
3. 删除编辑器里的默认内容。
4. 打开本仓库的 `ustc_evaluate.js`，复制全部代码并粘贴到油猴编辑器。
5. 按 `Ctrl+S` 保存脚本，并确认脚本处于启用状态。

## 使用

1. 打开中科大教学质量管理平台：`https://tqm.ustc.edu.cn/index.html`
2. 进入待评价的问卷页面。
3. 页面右上角出现“自动评教助手”面板后，选择填写模式：
   - 全选最好
   - 全选一般
   - 全选最差
   - 随机模式
4. 可按需调整这些选项：
   - 每份问卷随机模式：每份问卷随机使用一种填写模式。
   - 文本评价：可选择“全部跳过”、“全部填无”或“语料库中随机”。
5. 点击“开始填写”，脚本会自动填写、提交，并尝试切换到下一位教师或下一门课程。

运行中可以点击“暂停”临时停止，点击“继续”恢复；点击“重置”会停止运行并清空已完成计数。
