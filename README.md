# 中科大教学质量评价自动填写脚本

一个用于自动填写中国科学技术大学教学质量管理平台评教问卷的 Tampermonkey 用户脚本。

## ✨ 功能特点

- 🚀 **全自动填写** - 自动填写所有单选题和文本题
- 👥 **多教师支持** - 自动处理多个教师的评教问卷
- 📚 **多课程支持** - 自动切换到下一门课程继续评教
- 🎲 **多种填写模式** - 支持全选最好/最差/一般/随机四种模式
- ⏸️ **随时暂停** - 可随时暂停和继续评教过程
- 🎯 **断点续评** - 从当前位置继续,不会重复已评价的教师
- 🖱️ **可拖动面板** - 控制面板可自由拖动,不遮挡页面内容

## 📦 安装步骤

### 1. 安装 Tampermonkey 浏览器扩展

根据您使用的浏览器,点击对应链接安装:

- **Chrome/Edge**: [Chrome 网上应用店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- **Firefox**: [Firefox 附加组件](https://addons.mozilla.org/zh-CN/firefox/addon/tampermonkey/)
- **Safari**: [App Store](https://apps.apple.com/app/tampermonkey/id1482490089)

### 2. 安装脚本

1. 点击浏览器工具栏中的 **Tampermonkey 图标**
2. 选择 **"管理面板"**
3. 点击左侧 **"+"** 号(新建脚本)
4. 删除编辑器中的所有内容
5. 复制 `ustc_evaluate.js` 文件中的全部代码
6. 粘贴到编辑器中
7. 按 **Ctrl+S** (或 Cmd+S) 保存

## 🎮 使用方法

### 开始评教

1. 访问 [中科大教学质量管理平台](https://tqm.ustc.edu.cn/index.html)
2. 进入任意一个待评教的问卷页面
3. 页面右上角会自动出现 **"🤖 自动评教助手"** 控制面板
4. 根据需要选择填写模式:
   - **随机模式** - 每道题随机选择选项
   - **全选最好** - 所有题目选择最好的选项(第一个)
   - **全选最差** - 所有题目选择最差的选项(最后一个)
   - **全选一般** - 所有题目选择中间选项
5. 可选: 勾选 **"每份问卷随机模式"** 让每位教师的评价使用不同的随机模式
6. 点击 **"▶️ 开始填写"** 按钮

### 控制功能

- **暂停** - 点击 **"⏸ 暂停"** 按钮可随时暂停填写
- **继续** - 暂停后点击 **"▶️ 继续"** 按钮恢复填写
- **重置** - 点击 **"🔄 重置"** 按钮清零计数器并停止运行
- **拖动面板** - 按住面板空白处拖动到合适位置

### 自动流程

脚本会自动完成以下操作:

1. 填写当前教师的所有单选题
2. 填写文本题(从答案库中随机选择)
3. 点击"提交"按钮
4. 点击弹窗中的"下一位教师"或"下一门课程"按钮
5. 重复上述步骤,直到所有评教完成

### 完成提示

- 状态栏会实时显示 **"已完成 X 位教师"**
- 所有评教完成后,按钮会变为 **"✅ 全部完成"**
- 控制台会显示 **"🎉 所有问卷已处理完成!"**

## ⚙️ 配置说明

脚本支持在代码中修改配置(第15-38行):

```javascript
const CONFIG = {
    submitDelay: 500,        // 提交延迟时间(毫秒)
    fillMode: 'random',      // 默认填写模式
    randomMode: true,        // 是否每份问卷随机切换模式
    textAnswerPool: [...]    // 文本题答案库
};
```

## 🐛 常见问题

**Q: 脚本没有自动运行?**  
A: 检查 Tampermonkey 是否已启用,脚本是否已保存并启用。

**Q: 能否修改填写速度?**  
A: 可以修改代码中的延迟时间参数,但建议不要过快以避免被检测。

**Q: 暂停后能继续吗?**  
A: 可以,脚本会从当前位置继续,不会重复已评价的教师。

**Q: 控制面板挡住了内容?**  
A: 按住面板空白处拖动到合适位置即可。
